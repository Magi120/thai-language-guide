## Что это за проект

Полный гайд по изучению тайского языка с нуля до разговорного уровня. Создан как набор HTML-файлов в стиле Apple (белые кремовые тона, элегантный дизайн). Все файлы связаны навигацией между собой.

---

## Файлы проекта

| Файл | Содержание |
|------|-----------|
| `index.html` | Главная страница — красивое меню со ссылками на все части |
| `part1-roadmap.html` | Роадмап: 4 фазы обучения (30 недель), инструменты |
| `part2-foundations.html` | 5 правил грамматики, 6 структур предложений, фразовый банк |
| `part3-conversations.html` | 5 диалогов (заказ еды, направления, отель, шопинг, чат) |
| `part4-1000words.html` | 1000 самых используемых слов — поиск и фильтры по категориям |
| `part5-daily.html` | Ежедневная практика: 20/30/45 мин, трекер прогресса |
| `CLAUDE.md` | Этот файл — контекст проекта для Claude |
| `upload_to_github.py` | Скрипт для загрузки файлов на GitHub Pages |

## Стиль и предпочтения пользователя

- **Дизайн:** Apple-style, кремово-белый (#FAF8F4), золото (#B8976A), шрифт system-apple
- **Язык общения:** русский или английский
- **Стиль работы:** быстро, без лишних объяснений, сразу делать
- **Устройства:** домашний ПК, рабочий ноут, личный ноут, телефон
- **Браузер:** Firefox (залогинен в GitHub как magirator)
- **ОС:** Windows 11

## Как продолжить работу

Когда Magi говорит "прочитай CLAUDE.md" — ты знаешь весь контекст.

**Возможные следующие шаги:**
- Добавить новые разделы в гайд (например, тайский алфавит, тоны с аудио)
- Создать аналогичный гайд по другому языку
- Добавить Quiz / тест по словам в part4
- Запустить upload_to_github.py чтобы сайт появился в интернете
- Обновить файлы и перезагрузить на GitHub
